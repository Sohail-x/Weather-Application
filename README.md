# Weather Application
A lightweight web application built using Java Servlets, JSP, HTML5, and CSS3. This application fetches and displays real-time weather details like temperature, humidity, wind speed, and general weather conditions for any user-searched city.

# Features
    Live Weather Updates: Fetches real-time weather data via REST APIs.
    Dynamic Interface: Uses JSP to dynamically render weather metrics passed from Java Servlets.
    Clean UI: Responsive design using modern CSS styling.

# Project Structure :
Weather-Application/
├── MyServlet.java      # Servlet handling HTTP requests, API fetching, and data parsing
├── index.html          # Main landing page for user input
├── index.jsp           # Dynamic page displaying search results and weather data
└── style.css           # Custom styles for the user interface
